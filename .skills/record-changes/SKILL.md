# 变更留痕

本项目留痕铁律：**每次改动与每次问答都必须记录，只增不改、不删历史**。

## changelog.md（`docs/changelog.md`）

- 触发：任何对代码、配置、文档的**每一次修改**（新建、删除、重构、修复、依赖变更），一次逻辑变更一条；批量机械改动可合并为一条。
- 格式：追加一行/一段 `[YYYY-MM-DD HH:mm:ss] 内容`，按日期分组。
- **时间必须精确到年月日时分秒**（本地时间），禁止只写年月日。
- 只增不改：追加到对应日期分组末尾，不修改、不删除历史条目。

## chat.md（`docs/chat.md`）

- 触发：每次与用户的问答、方案、决策讨论结束后，记录**问题与结论**（便于回溯"为什么这么做"）。
- 格式：
  ```markdown
  ### Q：问题

  **结论**（YYYY-MM-DD HH:mm:ss）：结论内容
  ```
- 时间同样**精确到年月日时分秒**（本地时间）。
- 只增不改：追加到对应日期分区，历史问答保留。

## 功能清单（`docs/功能清单列表.md`）

- 每完成一个功能条目，更新对应状态（✅ / ◐ / ⏸），并补充备注。
- 新增功能组时按字母序号追加（如 S/T 节），不破坏既有编号。

## 验证记录联动

- 验证产物归档记录（`tests/verification/`）的时间字段同样精确到年月日时分秒（见 `test-verification` 技能）。
